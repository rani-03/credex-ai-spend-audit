

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- Vercel Deployment

## User Flow
User enters:
- AI tool
- Plan
- Monthly spend
- Team size
- Use case

The app calculates:
- Estimated overspending
- Recommended cheaper alternative
- Monthly savings
- Annual savings

Results are displayed instantly with:
- AI generated summary
- Save audit button
- Shareable link

## Scaling
If handling 10k audits/day:
- Add database
- Add caching
- Add authentication
- Add API rate limiting
- Move calculations to backend
